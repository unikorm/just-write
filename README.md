# just-write

A notepad that opens straight into writing. One file, no setup, no accounts, no choices to make.

## Why

Every note app asks something before it lets you write. Pick a notebook. Pick a note type. Give it a title. Tag it. Sync it. By the time you're done answering, the thought you opened the app for is gone.

'just-write' removes all of it. You tap the icon, the keyboard is up, the cursor is on a new line at the bottom. You write. That's the whole app.

## How it works

- **One file.** Everything you've ever written lives in a single plain text file.
- **New line, every time.** Opening the app puts you at the end of the file on a fresh line.
- **Scroll up to read.** Your history is right there above the cursor. No list, no search screen, no folders.
- **Nothing to save.** Text is written to disk as you type.

## What it deliberately doesn't have


- No sign-in, no account, no email
- No cloud, no sync, no server — the app never touches the network
- No titles, note types, tags, folders, or categories
- No formatting, no markdown toolbar, no rich text
- No settings screen worth opening
- No notifications, no streaks, no reminders
- No telemetry or analytics

## Your data

It's a `.txt` file on your device. Not a database, not a proprietary format. Open it in any text editor, copy it to a USB stick, email it to yourself, grep it. If this app disappears tomorrow, your writing doesn't.
